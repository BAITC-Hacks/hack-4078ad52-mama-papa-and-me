# AI-объяснения

Статус: архитектурный каркас. Исполняемая реализация отсутствует. Этапы — в [plans.md](../../plans.md); общие границы — в [карте архитектуры](../../docs/architecture/README.md).

## Ответственность

OpenAI-клиент, промпты, JSON-схема, ссылки на факты/источники и fallback.

## Внутренняя структура

Клиент, prompt, verify и fallback будут выделены по ответственности.

## Публичный интерфейс

Доверенный ScenarioReport + evidence + конфигурация → Explanation или обозначенный fallback. Числа не пересчитываются.

## Зависимости

contracts и официальный OpenAI SDK. Параметры получает от backend; не пишет в storage и не управляет UI.

## Проверки при реализации

Схема, факты, выдуманные источники/ВВП, инструкции внутри данных, таймаут, отказ/отсутствие ключа; реальный ограниченный запрос на P5.

Команды тестов появятся вместе с кодом. Изменение интерфейса сопровождается обновлением этого README, contracts и затронутых потребителей.
