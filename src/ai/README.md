# AI-объяснения

Актуальный прогресс — в [plans.md](../../plans.md), зависимости — в [карте архитектуры](../../docs/architecture/README.md).

## Ответственность

OpenAI-клиент, промпты, извлечение цитат, проверка структуры ответа и fallback.

## Внутренняя структура

index.ts: createAI, extractSources, verifyExplanation, fallback, PROMPT_VERSION.

## Публичный интерфейс

Доверенный отчёт и конфигурация → background response; объяснение содержит factIds/sourceIds. Подробности в AI-спецификации.

## Зависимости

contracts, официальный OpenAI SDK, server-only. Не пересчитывает числа и не пишет в БД.

## Проверки при реализации

Fake provider в integration; неизвестные ссылки отклоняются. Реальная проверка: чат о парках и финальный сценарий. Смысл текста не полностью проверяется автоматически.

При изменении публичного интерфейса обновляйте contracts, потребителей и этот README. Команды проверки: npm test, npm run typecheck, npm run lint; UI дополнительно npm run test:e2e.

urban-advisor-3: каждое утверждение требует factIds или sourceIds. Текст AI качественный; цифры, проценты, URL и распространённые числительные отклоняются. Числа выводит UI из evidence сервера. Это ограниченная лексическая защита: она не доказывает смысловую правильность тезиса или соответствие исследования вопросу. Fallback формируется сервером и не проходит как AI-текст.

Промпт v3 задаёт понятную последовательность вывода, короткие предложения и отдельные роли для игрового эффекта, риска и следующего действия. Мировой опыт предназначен для раскрываемого раздела. Fallback объясняет направление изменения и сохранившиеся проблемы на основе отчёта. Примеры и ограничения — в [проверке понятности](../../docs/reviews/ai-readability-2026-09-23.md).

Регрессии проверяют настоящие ответы и отсутствие ложных отказов для слов «сотрудничество», «сотрудники», «семинары». [Повторная приёмка](../../docs/reviews/ai-acceptance-2026-09-23.md) содержит живые случаи и ограничения.
