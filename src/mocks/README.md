# Демонстрационные данные

Статус: архитектурный каркас. Исполняемая реализация отсутствует. Этапы — в [plans.md](../../plans.md); общие границы — в [карте архитектуры](../../docs/architecture/README.md).

## Ответственность

Fixtures и mock-адаптеры для просмотра фронтенда до реализации backend.

## Внутренняя структура

Примеры успешного/ошибочного/ожидающего ответа, привязанные к конкретным портфелям.

## Публичный интерфейс

Те же contracts, что у будущего API; UI явно показывает демонстрационный режим.

## Зависимости

contracts и data. Реальный backend не импортирует mock-ответ как вычисленный результат.

## Проверки при реализации

Контрольный отчёт 56.54307 только для его портфеля; произвольный выбор не выдаёт этот Score как свой.

Команды тестов появятся вместе с кодом. Изменение интерфейса сопровождается обновлением этого README, contracts и затронутых потребителей.
