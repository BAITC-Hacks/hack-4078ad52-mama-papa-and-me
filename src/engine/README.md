# Расчётный движок

Статус: архитектурный каркас. Исполняемая реализация отсутствует. Этапы — в [plans.md](../../plans.md); общие границы — в [карте архитектуры](../../docs/architecture/README.md).

## Ответственность

Валидация пяти мер, лаги, синергии, clip, районные показатели и Score.

## Внутренняя структура

Чистые функции validate/effects/synergies/score; unit-тесты рядом с будущим кодом.

## Публичный интерфейс

ScenarioInput + Dataset → ошибки или ScenarioReport. Все данные передаются аргументами.

## Зависимости

Только contracts; запрещены React, Next.js, сеть, SQL и чтение env.

## Проверки при реализации

Score 52.55768/56.54307, порог 40, бюджет, конфликты, порядок, лаги и синергии. Исходный город считается отдельно от валидации пяти решений.

Команды тестов появятся вместе с кодом. Изменение интерфейса сопровождается обновлением этого README, contracts и затронутых потребителей.
