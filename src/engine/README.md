# Расчётный движок

Актуальный прогресс — в [plans.md](../../plans.md), зависимости — в [карте архитектуры](../../docs/architecture/README.md).

## Ответственность

Все правила набора и единственная runtime-реализация математики.

## Внутренняя структура

index.ts — validate, эффекты, синергии, clip, score, факты; engine.test.ts — инварианты.

## Публичный интерфейс

validate(input,dataset,requireFive), simulate(input,dataset,requireFive), baseline(dataset), canonicalSelections. Ошибки не содержат Score.

## Зависимости

Только contracts, данные передаются аргументами. Нет React, env, сети или БД.

## Проверки при реализации

Vitest: 52.55768/56.54307, бюджеты, пять мер, категории, районы, конфликты, версии, лаги, синергии, clip, порог <40, порядок и отсутствие мутаций.

При изменении публичного интерфейса обновляйте contracts, потребителей и этот README. Команды проверки: npm test, npm run typecheck, npm run lint; UI дополнительно npm run test:e2e.

Реестр facts дополнен количеством мер, расходами мер, индексами районов до/после/дельтой, средним/минимумом, вкладами после лага и синергиями. Математика Score и коэффициенты не изменены.
