# Каталог и исходные значения

Актуальный прогресс — в [plans.md](../../plans.md), зависимости — в [карте архитектуры](../../docs/architecture/README.md).

## Ответственность

Один runtime-набор районов, индикаторов, мер, весов и синергий.

## Внутренняя структура

index.ts: типизированный перенос исходника, версии astana-synthetic-1 / akim-1; data.test.ts: сверка всех чисел с шестью таблицами.

## Публичный интерфейс

dataset, categories, exampleSelections, scenarioInput. Полные эффекты не умножены на лаг заранее.

## Зависимости

Только типы contracts. Источник — docs/data/dataset-source.md.

## Проверки при реализации

Vitest сверяет веса, доли, все 50 показателей, стоимость/лаг/эффекты 14 мер, синергии и пример; Python Decimal независимо проверяет контрольные числа.

При изменении публичного интерфейса обновляйте contracts, потребителей и этот README. Команды проверки: npm test, npm run typecheck, npm run lint; UI дополнительно npm run test:e2e.
