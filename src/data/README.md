# Каталог и исходные значения

Статус: архитектурный каркас. Исполняемая реализация отсутствует. Этапы — в [plans.md](../../plans.md); общие границы — в [карте архитектуры](../../docs/architecture/README.md).

## Ответственность

Единственный runtime-набор районов, индикаторов, мер, весов, синергий и версий.

## Внутренняя структура

Типизированный набор переносится на P3 из docs/data/dataset-source.md; сейчас таблицы доступны только в источнике.

## Публичный интерфейс

Dataset + datasetVersion/rulesVersion для engine/backend и публичного UI-preview.

## Зависимости

Только contracts. Полные эффекты сохраняются без предварительного умножения на лаг.

## Проверки при реализации

5 районов, 10 индикаторов, 14 мер, уникальные ID, веса/доли = 1, сверка с исходником.

Команды тестов появятся вместе с кодом. Изменение интерфейса сопровождается обновлением этого README, contracts и затронутых потребителей.
