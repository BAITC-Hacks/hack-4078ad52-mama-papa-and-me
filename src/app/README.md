# Страницы и HTTP-адаптеры

Статус: архитектурный каркас. Исполняемая реализация отсутствует. Этапы — в [plans.md](../../plans.md); общие границы — в [карте архитектуры](../../docs/architecture/README.md).

## Ответственность

Композиция экранов, Next.js routing и тонкие Route Handlers. Бизнес-логика принадлежит backend.

## Внутренняя структура

page/layout и api/simulate, api/explain появятся по этапам; сейчас только README.

## Публичный интерфейс

HTTP-ввод → backend → HTTP-ответ; страницы используют UI.

## Зависимости

ui, backend, contracts; backend импортируется только серверной частью.

## Проверки при реализации

Проверить делегирование, схемы/HTTP-ошибки и отсутствие секретов в браузере.

Команды тестов появятся вместе с кодом. Изменение интерфейса сопровождается обновлением этого README, contracts и затронутых потребителей.
