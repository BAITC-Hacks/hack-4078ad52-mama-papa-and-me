# Игровой интерфейс

Статус: архитектурный каркас. Исполняемая реализация отсутствует. Этапы — в [plans.md](../../plans.md); общие границы — в [карте архитектуры](../../docs/architecture/README.md).

## Ответственность

Карта, каталог, портфель из пяти мер, бюджет, отчёт и состояния ожидания/ошибки.

## Внутренняя структура

components/ — элементы; features/ — пользовательские сценарии; styles/ — оформление.

## Публичный интерфейс

Выбор пользователя и HTTP-отчёты → доступные экранные состояния. Произвольный выбор не получает чужой mock-Score.

## Зависимости

contracts, engine/data для preview; mocks только для прототипа. Запрещены backend, ai, storage и config.

## Проверки при реализации

Клавиатура, 390/1440 px, выбор/удаление/сброс, лимиты, соответствие отчёта набору, отсутствие ошибок браузера.

Команды тестов появятся вместе с кодом. Изменение интерфейса сопровождается обновлением этого README, contracts и затронутых потребителей.
