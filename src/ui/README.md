# Игровой интерфейс

Актуальный прогресс — в [plans.md](../../plans.md), зависимости — в [карте архитектуры](../../docs/architecture/README.md).

## Ответственность

Карта, каталог, пять решений, отчёт, сохранение и AI-советник.

## Внутренняя структура

features/city-simulator.tsx, features/city-map.tsx; components/button.tsx, components/measure-card.tsx, utils.ts; styles/globals.css и styles/visual-theme.css.

## Публичный интерфейс

index.ts экспортирует CitySimulator и PreviewApp. CitySimulator по умолчанию использует HTTP; опциональные apiClient и demo предназначены для изолированного предпросмотра. Изменение портфеля проверяет engine; финал и сохранение основного приложения — HTTP. Черновик localStorage, текущий анализ sessionStorage. Предпросмотр использует отдельный префикс ключей и не смешивает данные с основным приложением.

Общая оболочка объединяет город, результат и архив. При смене экрана фокус переходит на main, прокрутка возвращается наверх. В городе доступны инструкция, шаги сценария и выбор района картой или кнопками. Отчёт показывает пять выбранных решений, график и раскрываемую подробную таблицу. Архив имеет отдельные состояния загрузки, ошибки и пустого списка.

## Зависимости

contracts, data, engine; React, Lucide, Recharts, Radix Slot. Серверные модули запрещены.

## Проверки при реализации

Playwright: полный сценарий, сохранение, fallback, конфликты, черновик, мобильный экран и клавиатура. Визуальная проверка 390/1440 px.

Для карточек: наведение раскрывает описание и увеличивает высоту; уход мыши закрывает предпросмотр; кнопка открывает описание без наведения; Enter/Space переключают, Escape закрывает. Раскрытие не перемещает кнопку добавления ниже описания. Проверяйте узкий экран 320 px и настройку reduced-motion.

При изменении публичного интерфейса обновляйте contracts, потребителей и этот README. Команды проверки: npm test, npm run typecheck, npm run lint; UI дополнительно npm run test:e2e.

AI вызывается только явно (вопрос/итоговый разбор), обычные правки не расходуют лимит. scenario-evidence.tsx показывает состав портфеля, вклады, критические показатели и формулу. ExplanationPanel раскрывает серверные основания каждого тезиса; дата источника названа датой получения. Итоговый разбор сохраняется со сценарием и восстанавливается без новой генерации.

Подача v3: главный вывод, польза, риски, действия; мировой опыт раскрывается отдельно. evidence-label.ts заменяет технические коды в подписях фактов на названия из каталога, не меняя ID и числа. Общая подсказка поясняет учебную модель и критический порог.
