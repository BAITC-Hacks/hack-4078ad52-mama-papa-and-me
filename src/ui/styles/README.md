# UI: styles

globals.css — Tailwind и базовая компоновка интерфейса. visual-theme.css подключается после него в корневом layout и задаёт актуальную палитру, типографику, карточки и адаптивное оформление. Стили не задают коэффициенты модели.

Тема: светлый тёплый фон, тёмно-зелёный основной цвет и песочный акцент. Шрифт — Segoe UI Variable / Segoe UI с системным fallback, без внешних загрузок. Основной текст 16–17 px, заголовки карточек 22–23 px. Каталог: три колонки на большом экране, две на планшете и одна на телефоне.

Карточка увеличивается по высоте при раскрытии описания; лёгкое масштабирование включено только для точного указателя с поддержкой hover. Кнопки действий стоят перед раскрываемым блоком. Клавиатурный фокус видим, prefers-reduced-motion отключает движение.

Границы и проверки — в [README UI](../README.md).
