# Автономный предпросмотр frontend

app.tsx использует настоящий CitySimulator с browser-api.ts вместо HTTP. Основная Next.js-страница этот модуль не импортирует и продолжает обращаться к серверу.

Предпросмотр считает через публичный engine, проверяет запросы через contracts, сохраняет сценарии в отдельный ключ localStorage `akim-preview-scenarios-v1`. Черновик и сессия также отделены префиксом `akim-preview`. Ключи, серверные модули и OpenAI не используются. Советник явно показывает демонстрационную справку, а не AI-ответ.

Проверять выбор районов, ограничения набора, расчёт контрольного портфеля, сохранение/открытие, восстановление черновика, переходы между экранами и мобильную раскладку. Это проверка frontend, а не замена серверным интеграционным тестам.
