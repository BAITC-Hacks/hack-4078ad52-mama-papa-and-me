# Серверная конфигурация

Статус: архитектурный каркас. Исполняемая реализация отсутствует. Этапы — в [plans.md](../../plans.md); общие границы — в [карте архитектуры](../../docs/architecture/README.md).

## Ответственность

Чтение и проверка окружения, defaults и параметры таймаутов; понятные ошибки настройки.

## Внутренняя структура

Серверный config export будет введён вместе с backend. Сейчас образец — корневой .env.example.

## Публичный интерфейс

OPENAI_API_KEY, OPENAI_MODEL, SQLITE_PATH → проверенная конфигурация без печати секретов. Путь SQLite относительно корня проекта.

## Зависимости

Не зависит от модулей проекта; допускается Zod. backend передаёт настройки адаптерам.

## Проверки при реализации

Пустой ключ не блокирует симуляцию, модель не заменяется молча, путь БД стабилен; значения ключей не логируются.

Команды тестов появятся вместе с кодом. Изменение интерфейса сопровождается обновлением этого README, contracts и затронутых потребителей.
