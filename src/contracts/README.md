# Общие контракты

Статус: архитектурный каркас. Исполняемая реализация отсутствует. Этапы — в [plans.md](../../plans.md); общие границы — в [карте архитектуры](../../docs/architecture/README.md).

## Ответственность

Типы и Zod-схемы входа/выхода, ошибок, версий и объектов модели.

## Внутренняя структура

Selection, ScenarioInput, Dataset, ScenarioReport, Explanation и коды ошибок появятся по этапам.

## Публичный интерфейс

Публичный index.ts экспортирует согласованные типы/схемы, без серверных реализаций.

## Зависимости

Ни одного другого модуля проекта; Zod разрешён. Нет env, SQL, HTTP-клиентов или побочных эффектов.

## Проверки при реализации

Районная/городская мера, неизвестные ID/версии, структурные ошибки; бизнес-ограничения набора остаются в engine.

Команды тестов появятся вместе с кодом. Изменение интерфейса сопровождается обновлением этого README, contracts и затронутых потребителей.
