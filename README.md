# Аким на 5 часов

Игровой AI-симулятор городского управления: пять решений, бюджет 100 и объяснение влияния на Astana Quality of Life Score.

**Состояние:** подготовлены документы, исходный датасет и каркас модулей. Запускаемого приложения, package.json, backend, AI-интеграции и SQLite-реализации пока нет. Следующий этап — локальный фронтенд с демонстрационными данными.

## Как будет работать симулятор

Все начинают с одинаковых пяти районов и бюджета 100. Игрок выбирает ровно пять уникальных мер из 14, максимум две на направление. Районной мере назначается один район; городская действует на весь город. Движок проверяет бюджет, конфликты и ограничения, применяет лаги и синергии. AI объясняет готовый отчёт и не придумывает числовые эффекты.

```text
Score = 0.7 × D_avg + 0.3 × min(D_d) − N_crit
```

Исходный Score — 52.55768. Контрольный набор M7/M8/M10 в Нуре, M12 по городу и M5 в Сарыарке стоит 95 и даёт 56.54307. Это синтетическая модель, не реальный прогноз Астаны или ВВП.

## Стек и локальный запуск

План: Next.js App Router, React, TypeScript strict, Tailwind CSS, shadcn/ui, Lucide, Recharts; Zod, OpenAI SDK / Responses API / gpt-6-astra; SQLite. Одно приложение на 127.0.0.1. Регистрация, облачная БД, Docker и облачный хостинг для запуска не нужны.

Сайт, расчёты и база работают на компьютере. OpenAI-модель работает на серверах OpenAI: для AI нужен интернет и собственный API-доступ. При его отсутствии расчёт должен работать с обозначенным шаблонным объяснением.

Сейчас команд установки и запуска приложения нет. На P1 появятся проверенные npm-команды и зафиксированные версии; окончательный путь установки проверяется на P7. Не запускайте npm ci до появления manifest/lock-файла.

При настройке будущего backend скопируйте [.env.example](.env.example) в локальный .env, если своего файла ещё нет. Ключ задаётся только на компьютере и не публикуется. SQLite создаётся на P6 в var/akim.sqlite; var/ и файлы БД исключены из Git.

```bash
python3 scripts/verify_dataset.py

```

Это проверки документации и данных, не тесты работающего симулятора. Результаты записаны в plans.md. Unit/API/UI-тесты, реальный вызов OpenAI и перезапуск SQLite относятся к будущим этапам.
