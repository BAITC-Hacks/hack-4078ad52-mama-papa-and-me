# Аким на 5 часов

> Статус: подготовительный каркас репозитория. На момент создания этого README исходный код симулятора, зависимости, набор данных и развёрнутая версия в репозитории отсутствуют.

## 1. Название проекта

**Аким на 5 часов** — AI-симулятор управления условным городом.

## 2. Краткое описание

Проект задуман как симулятор для городского управленца, аналитика или участника хакатона. Пользователь распределяет единый виртуальный бюджет между решениями в пяти направлениях: транспорт, озеленение, социальная инфраструктура, безопасность и городской сервис. Результатом должен стать итоговый **Astana Quality of Life Score** с объяснением сильных сторон, рисков и компромиссов сценария.

Полноценная реализация этой логики пока не добавлена в репозиторий.

## 3. Что реализовано

В текущей версии репозитория реализована только базовая безопасная конфигурация для будущей разработки:

- [`.gitignore`](.gitignore) исключает локальные файлы окружения, включая `.env`;
- [`.env.example`](.env.example) содержит пустую переменную `OPENAI_API_KEY` как пример будущей локальной конфигурации.

Пользовательский интерфейс, модель расчёта, AI-анализ, импорт данных, хранилище и API пока отсутствуют.

## 4. Как должно работать решение

Целевой пользовательский сценарий для будущей версии:

1. Пользователь видит единый доступный бюджет и исходные показатели районов.
2. Выбирает по одному управленческому решению в каждом из пяти направлений.
3. Система не позволяет превысить бюджет.
4. Расчётный модуль обновляет показатели районов и итоговый Astana Quality of Life Score.
5. AI формирует понятное объяснение влияния решений, рисков и возможных улучшений сценария.

Этот сценарий описывает цель проекта и не является заявлением о готовой функциональности.

## 5. Технологии

Технологический стек приложения пока не определён в коде репозитория.

Единственная подготовленная переменная окружения — `OPENAI_API_KEY`; она не подтверждает подключение OpenAI API или использование какой-либо конкретной AI-модели.

## 6. Архитектура проекта

Архитектура приложения пока не реализована. Планируемые компоненты — интерфейс симулятора, сервер расчёта сценариев, модуль AI-объяснений и источник синтетических данных — отсутствуют в текущем состоянии репозитория.

## 7. Установка и запуск

Запускаемого приложения и файлов зависимостей в репозитории пока нет, поэтому команды установки и запуска отсутствуют.

Для подготовки локальной конфигурации будущего приложения можно создать файл окружения:

```bash
cp .env.example .env
```

Значение `OPENAI_API_KEY` при необходимости добавляется локально в `.env`. Файл исключён из Git и не должен публиковаться.

## 8. Как проверить решение

Функциональная проверка симулятора пока невозможна: нет исполняемого кода, тестов, API или интерфейса.

Можно проверить только подготовленную конфигурацию:

```bash
git check-ignore .env
```

Ожидаемый результат — `.env`, что подтверждает исключение локального файла с секретами из Git.

## 9. Данные и интеграции

В репозитории пока нет синтетического датасета районов, перечня мероприятий, внешних интеграций или настроенных API.
