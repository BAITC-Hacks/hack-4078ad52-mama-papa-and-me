# Аким на 5 часов

Локальный игровой AI-симулятор: пять решений, бюджет 100, пять районов и Astana Quality of Life Score. Работают карта и каталог инициатив, расчёт последствий, AI-советник с веб-поиском и сохранение сценариев в SQLite.

## Запуск

Нужен Node.js 22.20+; проверенная версия менеджера пакетов — npm 11.20.0. Команды выполняются из корня проекта. Python 3.9+ нужен только для независимых проверок документации и исходных таблиц.

```bash
npx --yes npm@11.20.0 ci
npm run dev
```

Откройте [http://127.0.0.1:3000](http://127.0.0.1:3000). Остановка — Ctrl+C в терминале сервера. Сайт и API слушают только локальный адрес. Docker, облачная БД и деплой не требуются.

Для AI создайте `.env` по [.env.example](.env.example), если своего файла ещё нет, и укажите `OPENAI_API_KEY`. На macOS скрытые файлы показывает Cmd+Shift+точка; файл можно открыть командой `open -e .env`. После изменения окружения перезапустите сервер. Не заменяйте уже заполненный `.env` шаблоном.

```dotenv
OPENAI_API_KEY=
OPENAI_MODEL=gpt-6-astra
SQLITE_PATH=./var/akim.sqlite
```

Модель запускается на серверах OpenAI, локальный backend использует Responses API и reasoning `medium`. Для AI нужен интернет и доступ к API. Без ключа симуляция, отчёт и сохранение работают; советник показывает явно обозначенное шаблонное объяснение. `AI_ENABLED=false npm run dev` временно отключает платные вызовы даже при наличии ключа. Модель автоматически не заменяется.

Production-режим, после остановки dev-сервера:

```bash
npm run build
npm start
```

Порт можно изменить: `npm run dev -- --port 3001` или `npm start -- --port 3001`.

## Первый сценарий

1. Нажмите «Загрузить пример», затем «Рассчитать результат». Стоимость — 95, итог — **56,54**, прирост — **3,99**.
2. Вернитесь к городу, выберите район на схематичной карте и измените инициативы. Бюджет, несовместимость мер и лимит пяти решений проверяются сразу; сервер повторяет проверки.
3. Откройте AI-советника или задайте вопрос о конкретной инициативе. Итоговый отчёт содержит кнопку «Разобрать сценарий с AI».
4. Укажите название и сохраните результат на компьютере. Открывайте его в «Мои сценарии»; незавершённый выбор сохраняется в браузере.

Каждое принятое изменение портфеля запускает анализ хода. Просмотр карточки, переключение района карты, сброс и загрузка примера сами по себе AI не вызывают. Один анализ состоит из двух запросов: веб-исследование и структурированное объяснение. Это расходует API-токены и поиск; лимит приложения — шесть анализов в минуту на браузерную сессию, не денежный лимит. Старое ожидание отменяется при новом выборе; уже выполненная работа провайдера может быть оплачена.

## Расчёт и достоверность

Все начинают с одинакового синтетического датасета. Выберите ровно пять уникальных мер из 14, не больше двух на направление и стоимостью не выше 100. Не обязательно охватывать все пять направлений. Районные меры действуют в выбранном районе, городские — во всех пяти.

```text
Эффект = полный эффект × (8 − лаг) / 8
Score = 0.7 × средняя оценка с учётом населения + 0.3 × оценка слабейшего района − число показателей < 40
```

Синергии добавляются один раз; показатели обрезаются до 0–100 после суммирования. Горизонт — восемь кварталов. Исходный Score — 52.55768; контрольный — 56.54307. Формулы и ограничения подробно описаны в [plans.md](plans.md), исходник — в [датасете](docs/data/dataset-source.md).

Числа рассчитывает независимый движок; AI получает серверный отчёт. Советник ищет источники, объясняет пользу, риски и применимость к климату и экономическим условиям Астаны. Ссылки выводятся из цитат реального поискового ответа. Схема и идентификаторы проверяются программно, смысл каждого тезиса требует экспертной оценки. Исследования не меняют игровые коэффициенты. Прирост ВВП, зарплат и здоровья эта модель не рассчитывает; игровой Score не является прогнозом реального города.

## Проверки

```bash
npm test
npm run typecheck
npm run lint
npm run check:data
npm run check:docs
npx playwright install chromium

npm run build
```

Vitest проверяет исходные числа, правила, серверные границы, сохранение и жизненный цикл AI. Playwright запускает отдельное приложение на 127.0.0.1:3100 с `AI_ENABLED=false`, отдельной сборкой и БД. Автотесты не вызывают OpenAI. Реальная интеграция проверена отдельно на вопросе о парках и итоговом сценарии; результаты и ограничения — в [plans.md](plans.md).

## Локальные данные и ограничения MVP

SQLite создаётся автоматически в `var/akim.sqlite`; сценарии и AI-задачи переживают перезапуск сервера. Версии данных, правил, промпта и модель сохраняются с соответствующими результатами. `.env`, `var/` и файлы SQLite исключены из Git. Ключ не передаётся браузеру. Черновик — в localStorage, идентификатор сессии и текущего анализа — в sessionStorage.

Длительный анализ выполняется в фоне OpenAI. Браузер опрашивает локальный статус; переход от исследования к объяснению происходит при опросе. Закрытие вкладки может отложить этот переход. Общий лимит ожидания — три минуты; готовое финальное объяснение возвращается и при позднем опросе. Автоматических повторных платных запросов после сбоя нет. При ошибке расчёт остаётся доступным с шаблонным объяснением.

Пока нет многопользовательских аккаунтов, рейтинга команд, случайных событий, экспорта презентации и откалиброванной модели реального города. Приложение рассчитано на работу на одном компьютере. Следующий этап — просмотр владельцем и улучшение механики и объяснений по его обратной связи.

[AGENTS.md](AGENTS.md) — правила агента; [plans.md](plans.md) — актуальное состояние, решения и проверки; [мировые практики](docs/research/README.md) — справочные источники.
