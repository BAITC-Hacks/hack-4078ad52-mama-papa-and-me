# Локальная интеграция OpenAI: GPT-6 Astra

Реализовано в [src/ai](../../../src/ai/README.md) и [backend](../../../src/backend/README.md). Название исторического каталога не означает установки плагина Superpowers. Актуальные результаты — в [plans.md](../../../plans.md).

## Вход и модель

Локальный backend проверяет исходный выбор, пересчитывает ScenarioReport и передаёт его модели `gpt-6-astra` с reasoning `medium`. Ключ читается только сервером из .env. Стоимости и Score клиента не принимаются. Для анализа хода передаются также числовые факты предыдущего набора с префиксом previous.

## Два этапа

1. Responses API: background=true, web_search, tool_choice=required, search_context_size=medium, max_output_tokens=5000. Модель исследует вопрос/меры и ищет первичные источники и ограничения применимости к Астане.
2. Responses API: background=true, Structured Outputs через Zod, max_output_tokens=7000. Вход — доверенные числа, текст исследования и реестр цитат. Выход — summary, strengths, risks, recommendations, context, limitations.

В обоих этапах Astra medium. SDK timeout — 25 секунд на сетевую операцию, maxRetries=0. Это не ограничение времени самой фоновой генерации. Локальный дедлайн анализа — 180 секунд; лимит — шесть стартов в минуту на sessionId. Модель при ошибке автоматически не заменяется.

Реестр источников формируется из url_citation поискового ответа, допускает только http/https, максимум 12 записей. UI строит ссылки по sourceIds. Проверяются JSON-схема, существование factIds/sourceIds и наличие источников у тезисов context. Это проверка структуры и происхождения ссылок, не автоматическое доказательство достоверности свободного текста или качества каждого исследования.

## Промпт и ограничения

Версия urban-advisor-3. Промпт отделяет синтетические коэффициенты от исследований, требует учитывать климат, сезонность, обслуживание, доступность и экономические условия; неподтверждённые местные параметры отмечать как пробелы. Источники/вопрос — данные, а не инструкции. Модель не меняет правила, не имеет shell/SQL-инструментов и не рассчитывает выдуманный ВВП. Сравнение без пересчитанного кандидата не считается доказательством улучшения.

Подбор мер пересчитывается без платных запросов; UI запускает только явный чат или итоговый разбор. Контракт step оставлен для совместимости. Чат доступен при любом допустимом наборе, final требует пять мер. Набор и вопрос уходят на серверы OpenAI. API и поиск оплачиваются отдельно от подписки на приложение ChatGPT/Codex; приложение не устанавливает денежный бюджет аккаунта.

## Устойчивость

SQLite хранит задачу перед обращением к OpenAI, ключи дедупликации и переходы. Браузер опрашивает локальный API и восстанавливает ID текущего анализа из sessionStorage после перезагрузки. Закрытая вкладка не выполняет переходы фаз. Отмена/новый выбор не позволяют позднему ответу заменить текущий результат. При истечении дедлайна не начинается новый платный этап; готовый финальный response возвращается при позднем опросе.

При отсутствии ключа, ошибке модели/сети, отсутствии цитат или невалидном JSON возвращается маркированный fallback. Детерминированный отчёт остаётся доступным. Нет автоматических платных повторов; пользователь может явно повторить запрос.

## Проверки

Vitest с fake provider: два этапа, ссылки/схема, usage, дедупликация, cancellation, timeout, пауза браузера, прерванный запуск и скрытие деталей провайдерских ошибок. Отдельно выполнены реальные чат и итоговый анализ; оба дали объяснение и по четыре цитируемых источника. Автотесты не расходуют API.

Источники реализации: [GPT-6 Astra](https://developers.openai.com/api/docs/models/gpt-6-astra), [web search](https://developers.openai.com/api/docs/guides/tools-web-search), [background mode](https://developers.openai.com/api/docs/guides/background), [prompt engineering](https://developers.openai.com/api/docs/guides/prompt-engineering). Проверены 2026-09-23.

В версии urban-advisor-3 числовые утверждения вынесены из свободного AI-текста в отображаемые серверные факты. Все тезисы должны иметь основание. Лексическая проверка цифр и распространённых числительных не заменяет экспертную оценку смысла.

## Понятность вывода v3

Главный результат выводится до подробностей. Промпт требует конкретных мер, районов и показателей, простого русского языка, коротких предложений и практичного следующего действия. Внешний опыт раскрывается отдельно; существенные риски остаются в основном тексте. Числовая защита не ослаблена. Доказательства проверки и примеры — в [отчёте](../../reviews/ai-readability-2026-09-23.md).
