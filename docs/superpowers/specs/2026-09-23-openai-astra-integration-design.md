# Локальная интеграция OpenAI: GPT-6 Astra

Статус: проектное решение для P5, не реализовано. Название исторического каталога не означает, что плагин Superpowers установлен. Актуальные инструкции — в [AGENTS.md](../../../AGENTS.md), прогресс — в [plans.md](../../../plans.md).

## Поток

Браузер → локальный HTTP-адаптер → backend → engine → доверенный ScenarioReport → ai → OpenAI Responses API → проверка объяснения → UI. Backend сохраняет результат через storage после реализации SQLite на P6.

Сайт и backend запускаются на 127.0.0.1. OpenAI-модель работает удалённо; ключ используется только локальным сервером. Выбор облачного хостинга для этого проекта не требуется.

## Вход и результат

Браузер передаёт исходные решения и версии, а не доверенный Score. Backend проверяет выбор и рассчитывает отчёт перед AI. Модель `gpt-6-astra`, серверный default OPENAI_MODEL; API-ключ — OPENAI_API_KEY.

Модуль ai получает отчёт, factIds, отобранные evidence-карточки и настройки клиента. Выход — структурированное объяснение с summary, strengths, risks, recommendations, evidence, limitations и mode ai/fallback. Ссылки строятся из проверенного реестра источников. Числа и альтернативы берутся из готовых расчётов.

## Ожидание и ошибки

Запрос запускается кнопкой анализа после выбора пяти мер. Изменение портфеля не запускает AI автоматически. UI показывает ожидание и привязывает результат к исходному набору; отмена ожидания и поздний ответ не изменяют новый сценарий.

Backend управляет статусом, ограниченными повторными попытками, таймаутом и размером ответа. На P5 процесс может хранить состояние в памяти; после его перезапуска нет автоматического платного повторения. Для долгой генерации проверяется background mode OpenAI. Точные параметры SDK проверяются по официальной документации при интеграции.

Без ключа, при ошибке модели или невалидном ответе расчёт остаётся доступным с обозначенным шаблонным объяснением. Недоступность модели не приводит к молчаливой смене модели.

## Проверка на P5

Схема и факты, ссылки, отсутствие ключа в клиенте/логах, ошибка и timeout, устаревший ответ, выдуманный ВВП, инструкции внутри данных. Один ограниченный реальный запрос подтверждает интеграцию; до этого она не считается работающей. API-модуль не пишет в SQLite и не меняет правила симуляции.
