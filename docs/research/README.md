# Мировые практики: источники и план исследования

Рассматривать конкретные политики и измеренные результаты. Высокий ВВП на душу населения — возможный фильтр отбора стран, но не доказательство причинной связи с устройством власти или отдельной мерой. Для будущего сравнения выбрать один год и одну метрику: например, ВВП на душу по ППС в постоянных международных долларах, с единым источником World Bank. До загрузки сопоставимых данных не присваивать странам места в рейтинге.

Начальные источники проверены 2026-09-23. Это материалы для карточек контекста; величины эффектов из них не перенесены в симулятор.

| Тема / мера | Первичный источник и подтверждённая идея | Ограничение для нашего проекта |
| --- | --- | --- |
| Транспорт / M1 | [LTA Singapore, 09.03.2022](https://www.lta.gov.sg/content/ltagov/en/newsroom/2022/3/news-releases/reimagining-road-space-for-smoother-and-greener-commutes.html): приоритетные транспортные коридоры и перераспределение дорожного пространства | Описание программы не доказывает эффект `+6/+9`; значения берутся из датасета |
| Озеленение / M4, M6 | [NParks: City in Nature Research Programme](https://www.nparks.gov.sg/services/research-programmes/city-in-nature-research-programme): исследовательская основа городской зелени, экологической и климатической устойчивости | Климат и эксплуатация в Астане отличаются; не переносить величины эффекта напрямую |
| Соцсфера / M7 | [World Bank: Education](https://www.worldbank.org/en/programs/knowledge-for-change/brief/Education): исследование долгосрочных связей доступа/качества образования, навыков и продуктивности | Это исследовательская рамка, не доказательство, что строительство школы немедленно повышает ВВП |
| Безопасность / M11 | [Trafikverket Sweden: Vision Zero](https://bransch.trafikverket.se/en/startpage/operations/Operations-road/vision-zero-academy/This-is-Vision-Zero/): совместное проектирование дорог, транспорта и условий для человека | Не сводить дорожную безопасность только к камерам и не обещать нулевую аварийность |
| Городской сервис / M12 | [Singapore MSO: OneService factsheet](https://www.mnd.gov.sg/docs/default-source/mnd-documents/newsroom/annex-a_factsheet-1.pdf): обращения по проблемам, отслеживание рассмотрения и карта заявок | Функции платформы сами по себе не доказывают сокращение сроков; дата документа в прочитанном тексте не указана |
| Оценка благополучия | [OECD: Well-being and beyond GDP](https://www.oecd.org/en/topics/well-being-and-beyond-gdp.html): оценка экономических, социальных и экологических результатов | Astana Score остаётся учебным индексом; не выдавать его за метрику OECD |

На P5 расширить набор: изучить результаты образования Финляндии/Эстонии по официальным материалам OECD и национальных ведомств; добавить городской кейс по первичной медицине или коммунальным сетям. Эти кейсы пока не исследованы и не используются как утверждения о лучшей практике.

Формат карточки: `id`, страна/город, мера и соответствующие indicatorIds, механизм, источник/URL/издатель, дата публикации или `null`, дата проверки, период наблюдения, дизайн исследования, подтверждённый результат, неизвестные значения, условия переноса, ограничения. Различать описание политики, наблюдаемую связь и причинную оценку. Для сильного причинного утверждения искать первичное исследование с контрольной группой/другой обоснованной идентификацией. При недостатке данных писать об ограничении.
