## Что остаётся ограничением

1. Лексическая проверка числового текста и существование factId не доказывают смысловую правильность. Например, неверная причинная связь без цифр всё ещё требует оценки. Более редкие словесные записи количеств могут обойти ограниченный словарь. Из интерфейса числа берутся из движка, но все свободные утверждения AI не становятся автоматически истинными.
2. Проверен один новый реальный ответ. Нужна серия примеров с разными портфелями, вопросами и провокациями для измерения частоты ошибок/fallback. Это следующий этап качества, не незавершённый локальный запуск.
3. AI не вычисляет улучшенный альтернативный портфель: рекомендации качественные. Для функции «сделать лучше» нужен перебор допустимых замен через движок с показом цены и изменения Score; только затем объяснение AI.
4. Реальные строительные, эксплуатационные расходы, кадры, климатические риски и распределительные эффекты не калиброваны. Данные учебные; условный Score не прогноз реального благополучия.
5. Публичный доступ жюри, многопользовательское хранение и денежные ограничения API остаются отдельной серверной задачей. Лимит запросов не ограничивает денежный расход; исследование с поиском остаётся платным.
6. Сравнение команд, случайные события и экспорт презентации — опциональные возможности кейса, в это усиление не включены.
