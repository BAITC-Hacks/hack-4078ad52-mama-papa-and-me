Это ограниченная выборка, а не гарантия безошибочности всех будущих генераций.

## Найдено и исправлено

1. **Ложный отказ валидатора.** Проверка числительных принимала «сотрудничества» за числительное из-за слишком широкого шаблона «сот…». Воспроизведено на настоящем ответе. Обнаружен и исправлен аналогичный случай «семинары». Обычные слова теперь проходят, числительные «сотня», «сотни», «семи» по-прежнему отклоняются. Добавлены регрессии на слова и четыре настоящих ответа.
2. **Повторное сохранение старого разбора.** Открытый архивный сценарий с промптом v2 нельзя было сохранить после перехода на v3. Теперь готовый AI-разбор той же версии данных/правил и того же набора мер повторно проходит актуальную проверку перед сохранением. Версия промпта в архиве не меняется. Непрошедший проверку текст требует нового разбора. Исправление проверено тестом и вручную.
3. **Неоднозначная подпись района.** Статическое описание исходных проблем выглядело как описание результата. Оно помечено «Исходная ситуация».
4. **Ошибка тестового скрипта.** Для чата с пятью мерами эталон сначала считался в preview, хотя сервер использовал final. Поэтому проверка оснований ошибочно сообщила о несовпадении полей Score. Режим исправлен; отдельная сверка без новой генерации подтвердила все значения. Исходный журнал не переписан.

## Воспроизведение

Обычные проверки не расходуют API:
```sh
npm test
npm run test:e2e
npm run lint
npm run typecheck
npm run build
npm run check:data
npm run check:docs
```

При работающем локальном сервере скрипт показывает список без генерации:
```sh
node scripts/evaluate-ai.mjs
```

Явный платный запуск всех четырёх случаев или одного:
```sh
node scripts/evaluate-ai.mjs --live
node scripts/evaluate-ai.mjs --live --case=negative-side-effect
```

Скрипт сохраняет локальные результаты в игнорируемом Git каталоге var/ai-evals. Проверяет статус и числовые основания, но не выставляет автоматическую оценку смысловой достоверности. Исходные прогоны: 2026-09-23T11-58-16.616Z, 2026-09-23T12-02-14.961Z, 2026-09-23T12-05-02.462Z.

## Ограничения

Свободный текст и применимость международных исследований не могут быть полностью проверены схемой JSON и поиском числительных. Выборочно сверены первичные материалы WHO о первичной медицине и OECD о сочетании цифрового и очного участия; полного экспертного аудита всех источников не проводилось. Реальный город, кадровая обеспеченность, климатическая пригодность конкретных объектов и экономические эффекты не моделируются.

Сильная сторона проверенных ответов — понятное разделение игрового эффекта, риска и действия. Дальнейшее улучшение — расширять выборку и проводить отдельную смысловую оценку; не объявлять все будущие ответы заведомо верными.
