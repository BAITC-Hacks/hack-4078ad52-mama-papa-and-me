# Проверки документации и исходных данных

Python 3.9+, только стандартная библиотека; выполнение из корня репозитория.

- `python3 scripts/check_docs.py` — структура README, локальные ссылки, регистр инструкции и конфигурация исключений.
- `python3 scripts/verify_dataset.py` — шесть таблиц исходного Markdown, веса, доли и контрольные значения.

Скрипты ничего не записывают и не выполняют сетевые запросы. Они не заменяют будущие Vitest/Playwright и production-движок.
