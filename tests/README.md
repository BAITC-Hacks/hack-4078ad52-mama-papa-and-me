# Проверки приложения

Статус: исполняемых тестов приложения нет. План — в [plans.md](../plans.md).

- Unit-тесты на Vitest размещаются рядом с будущими модулями.
- [integration](integration/README.md) — контракты и взаимодействие серверных частей.
- [e2e](e2e/README.md) — браузерные сценарии Playwright.

Тесты используют фикстуры и временные локальные данные. OpenAI заменяется mock-адаптером, кроме отдельно запущенной ограниченной проверки интеграции на P5. Сейчас доступны лишь проверки исходного датасета и документации в [scripts](../scripts/README.md).
