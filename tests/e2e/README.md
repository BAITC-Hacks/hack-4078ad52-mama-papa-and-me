# Браузерные сценарии

`npx playwright install chromium`, затем `npm run test:e2e`. Конфигурация запускает Next на 127.0.0.1:3100, отдельную сборку .next-e2e и var/e2e.sqlite, AI_ENABLED=false. Порт должен быть свободен. Реальный ключ не используется.

game.spec.ts проверяет полный игровой путь и 56,54, сохранение/открытие, fallback, конфликт мер, восстановление черновика, клавиатуру, 390 px без переполнения и отклонение подмены Score/чужого Origin. Playwright сохраняет trace при сбое в test-results; артефакты исключены из Git. [Результаты](../../plans.md).

Дополнительный сценарий проверяет отсутствие POST /api/analyses при подборе мер, подробный отчёт, основания и сохранение/открытие объяснения без новой генерации.

Тест подачи объяснения использует фиксированный тестовый AI-ответ: главный вывод/действия видны, мировой опыт раскрывается отдельно, технический код факта заменяется названием, ссылка сохраняется; ширина 390 px.

Изменение школьного района после открытия архива скрывает прежнее объяснение без новой генерации; новый расчёт даёт 55,30. Статическое описание района помечено как исходная ситуация.

После объединения frontend добавлен седьмой сценарий: /preview на 320 px считает и сохраняет без HTTP API, маркирует демо-ответ и не переносит черновик/AI-состояние в основное приложение.
