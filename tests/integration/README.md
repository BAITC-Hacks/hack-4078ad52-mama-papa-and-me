# Интеграционные проверки

server.test.ts проверяет серверные границы, пересчёт, сохранение/открытие SQLite, fallback, дедупликацию и неизвестные factIds. analysis.test.ts заменяет только OpenAI-адаптер и проверяет durable lifecycle: два этапа, usage, таймаут, поздний ответ, отмену, прерванный переход и отсутствие цитат.

Запуск: `npm test`. Каждый тест использует временный путь БД; ключи и база пользователя не нужны. [Текущие результаты](../../plans.md).
