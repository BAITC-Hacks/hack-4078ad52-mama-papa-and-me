# Интеграционные проверки

server.test.ts проверяет серверные границы, пересчёт, сохранение/открытие SQLite, fallback, дедупликацию и неизвестные factIds. analysis.test.ts заменяет только OpenAI-адаптер и проверяет durable lifecycle: два этапа, usage, таймаут, поздний ответ, отмену, прерванный переход и отсутствие цитат.

Запуск: `npm test`. Каждый тест использует временный путь БД; ключи и база пользователя не нужны. [Текущие результаты](../../plans.md).

Добавлены регрессии параллельных запусков, дедупликации во время отмены, чужого requestId, сохранения только соответствующего анализа и поздней отмены. evidence.test.ts проверяет отказ при вымышленных количествах и отсутствующих основаниях.

readability.test.ts проверяет основания и смысловые ветки шаблонного ответа, а также совместимость понятного русского текста с валидатором. Это не автоматическое доказательство понятности всех генераций.

В tests/fixtures сохранены четыре реальных ответа для проверки совместимости с текущими основаниями. Добавлены регрессии ложных числительных и повторного сохранения старой версии промпта с актуальной проверкой текста.
